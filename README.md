# Давай напишем

Скилл для написания и редактирования русскоязычных текстов от лица бренда. Версия 0.11 от 16 ноября 2026 года.

Помогает выстроить пост, сохранить голос бренда, проверить факты и убрать шаблонные обороты. Для работы нужны описание проекта и исходные факты. Качество результата зависит от модели и брифа; текст нужно проверить перед публикацией.

## Установка в Codex

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Скопируйте папку `kopirayter` целиком в каталог skills вашего Codex. Обычно это `%USERPROFILE%\.codex\skills` в Windows или `~/.codex/skills` в macOS/Linux. При настроенном `CODEX_HOME` используйте его каталог `skills`.
3. Если такая папка уже есть, сначала сохраните её копию.
4. Откройте новый чат и вызовите `$kopirayter`.

Пример запроса:

> Используй $kopirayter. Напиши пост для нашего бренда. Описание проекта: … Аудитория: … Цель поста: … Подтверждённые факты: …

Для правки: «Сделай короче и теплее, сохрани все факты».

## Состав

Основные инструкции находятся в `kopirayter/SKILL.md`, дополнительные правила в `kopirayter/references`. Скачивайте всю папку, а не один файл. Это скилл, а не Telegram-бот; он не содержит ключей API или базы проектов.
